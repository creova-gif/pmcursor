## Vision

### 10x Check
For ~2x the current codebase size (~600 additional lines across modular extractors, CLI subcommands, webhook verifier, and HTML canvas generator), PMCursor evolves from a Python-only PRD linter into a full-stack, self-healing Product-to-Code Contract Engine:
1. Indexes contracts across Python (`Pydantic`, `dataclass`, `FastAPI`), TypeScript (`Zod`, `interface`), `OpenAPI` (`.json`/`.yaml`), `SQL` DDL (`CREATE TABLE`), `ADRs`, and `Telemetry` (`track_event`, `Langfuse`, `BigQuery`, `PostHog`, `Vercel Analytics`).
2. Self-heals shifted `file:line` citations and updated field types in Markdown PRDs via `pmcursor fix-prd --prd <path> [--dry-run | --write]`.
3. Maps unified `git diff` hunks to impacted `RepoMap` contracts and PRD sections via `pmcursor pr-impact` and an HMAC-SHA256-verified GitHub webhook handler in `api/`.
4. Renders a zero-dependency, interactive Split-Pane Spec Canvas (`pmcursor canvas --prd <path> --output <html_path>`) pairing the living PRD on the left with filterable AST contract cards and alignment scores on the right.

### Platonic Ideal
A Product Manager opens their repository in Cursor or runs `pmcursor canvas --prd PRD.md`. Left pane: their living PRD with inline status badges on every `Model.field`, `METHOD /route`, `ADR-NNN`, `file:line`, and `telemetry: event(prop)`. Right pane: the exact live code contract from Python/Pydantic, TypeScript/Zod, OpenAPI YAML/JSON, SQL DDL, or telemetry calls, plus a one-command `pmcursor fix-prd` auto-healer and a GitHub PR impact commenter that flags spec drift on every pull request in under 50ms.
